# Grammar Structure Schema

Defines how grammar structures are annotated in vocabulary manifests,
highlighted in the reading view, and connected to the English Grammar
Profile (EGP) and L1 Spanish overlay.

---

## Architecture Overview

Three data layers work together:

| Layer | File | Lives in | Purpose |
|---|---|---|---|
| **EGP lookup** | `src/data/egpLookup.js` | Relato (bundled) | 996 A1-B2 grammar constructs with CEFR level, category, can-do statement. Authoritative source for level assignment. |
| **L1 Spanish overlay** | `data/egp_spanish_overlay.json` | Graded readers project | Spanish-specific content: pattern formula, explanation in Spanish, L1 contrast, bilingual examples. Thin file; only entries for structures used in our graded readers. |
| **Per-book manifest** | `books.vocabulary_manifest` JSONB | Supabase (per book) | `type: "structure"` entries alongside existing `"word"` and `"particle"` entries. References an EGP construct ID + provides book-specific instances. |

Data flow:

```
EGP XLSX (Cambridge)
  --> build-data.mjs --> egpLookup.js (bundled in Relato)

Graded reader authoring
  --> egp_spanish_overlay.json (shared across books, incremental)
  --> vocabulary_manifest.json per book (structure entries + instances)

At render time:
  egpLookup[egp_id]          --> level, category, guideword, can-do
  spanishOverlay[egp_id]     --> pattern, explanation_es, spanish_contrast
  manifest.entries[key]      --> instances to find in chapter text
```

## EGP Lookup (`egpLookup.js`)

Generated by `scripts/build-data.mjs` from `scripts/egpo.xlsx`.
Keyed by EGP construct ID (integer). Filtered to A1-B2.

```js
export const egpLookup = {
  382: {
    superCategory: "FUTURE",
    subCategory: "future simple (with will and shall)",
    level: "A1",
    guideword: "FORM: AFFIRMATIVE 'WILL'",
    canDo: "Can use the affirmative forms 'will' and ''ll'.",
    example: "I will see you soon. (A1 BREAKTHROUGH; 2009; Urdu; Pass)"
  },
  // ...996 entries total
};
```

### Field reference

| Field | Description |
|---|---|
| `superCategory` | Top-level grammar domain: ADJECTIVES, ADVERBS, CLAUSES, CONJUNCTIONS, DETERMINERS, DISCOURSE MARKERS, FOCUS, FUTURE, MODALITY, NEGATION, NOUNS, PASSIVES, PAST, PREPOSITIONS, PRESENT, PRONOUNS, QUESTIONS, REPORTED SPEECH, VERBS |
| `subCategory` | Specific grammar area within the supercategory (e.g., "future simple (with will and shall)", "relative", "phrasal") |
| `level` | CEFR level: A1, A2, B1, B2. Empirically derived from the Cambridge Learner Corpus. |
| `guideword` | Short label describing form or use (e.g., "FORM: AFFIRMATIVE 'WILL'", "USE: PREDICTIONS WITH 'WILL'") |
| `canDo` | What the learner can do at this level. Competency statement. |
| `example` | Learner example from the Cambridge Learner Corpus (first example only). |

## L1 Spanish Overlay (`egp_spanish_overlay.json`)

Lives in the graded readers project at `data/egp_spanish_overlay.json`.
Bundled into Relato as a static data file alongside `egpLookup.js`.

This is the only file that requires substantial authoring. It provides
the Spanish-specific pedagogical content that EGP does not include.
Authored incrementally: a new entry is added only when a structure
appears in a graded reader for the first time.

Keyed by EGP construct ID (matching `egpLookup.js`).

```json
{
  "382": {
    "pattern": "subject + will + verb (base form)",
    "explanation_es": "Usamos 'will + verbo' para hablar del futuro. El verbo despues de 'will' siempre va en forma base (sin conjugar).",
    "spanish_contrast": "En espanol se usa el futuro simple (vere, sonreira) -- una sola palabra conjugada. En ingles se necesitan dos: 'will' + verbo base.",
    "examples": [
      { "en": "I will see you tomorrow.", "es": "Te vere manana." },
      { "en": "She will come later.", "es": "Ella vendra despues." }
    ]
  },
  "1095": {
    "pattern": "there + is + singular noun",
    "explanation_es": "'There is' se usa para decir que algo existe o esta presente en un lugar.",
    "spanish_contrast": "En espanol se usa 'hay' para singular y plural sin cambio. En ingles hay que elegir 'is' o 'are' segun el numero.",
    "examples": [
      { "en": "There is a cat on the table.", "es": "Hay un gato en la mesa." },
      { "en": "There is some water.", "es": "Hay agua." }
    ]
  },
  "1058": {
    "pattern": "verb + pronoun + particle",
    "explanation_es": "Algunos verbos compuestos se pueden separar -- el pronombre va entre el verbo y la particula. Con pronombres, la separacion es obligatoria.",
    "spanish_contrast": "En espanol los verbos reflexivos no se separan: 'ponerse' es una sola unidad. En ingles, 'pick it up' separa 'pick' y 'up'.",
    "examples": [
      { "en": "She picked it up.", "es": "Ella lo recogio." },
      { "en": "Put it on.", "es": "Pontelo." }
    ]
  }
}
```

### Field reference

| Field | Required | Description |
|---|---|---|
| *(key)* | -- | EGP construct ID as string. Must match a key in `egpLookup.js`. |
| `pattern` | yes | Structural formula in plain English (e.g., "subject + will + verb (base form)"). Shown in popup. |
| `explanation_es` | yes | Learner-facing grammar explanation in Spanish. 2-3 sentences max. |
| `spanish_contrast` | yes | How this structure differs from the Spanish equivalent. The L1 bridge. |
| `examples` | yes | 2-3 bilingual example pairs. Generic (not from any specific book). Array of `{ en, es }`. |

### Authoring guidelines

- One entry per EGP construct ID, shared across all books.
- Only create an entry when a structure first appears in a graded reader.
  Typical growth: 5-10 new entries per book, plateauing as common
  structures are covered.
- `explanation_es` should be accessible at the book's target CEFR level.
  An A1 book's overlay entries use simpler Spanish than a B2 book's.
- `spanish_contrast` is the most pedagogically valuable field. Focus on
  what will trip up a Spanish speaker specifically.

## Per-Book Manifest Entry (`type: "structure"`)

Added to the vocabulary manifest alongside existing `type: "word"` and
`type: "particle"` entries. Each entry identifies a grammar structure
that appears in the chapter and provides the specific instances to
highlight.

```json
{
  "book": "the_cookie",
  "chapter": 1,
  "target_cefr": "A1",
  "generated": "2026-06-14",
  "entries": {

    "watch": {
      "type": "word",
      "pos": "v",
      "cefr": "A1",
      "spanish": "observar",
      "note": "Used as 'observe people', not as noun (reloj)"
    },

    "put on": {
      "type": "particle",
      "compositionality": "non-compositional",
      "cefr": "A1",
      "spanish": "ponerse (ropa)"
    },

    "egp_382__ch01": {
      "type": "structure",
      "egp_id": 382,
      "instances": ["will see", "will smile"]
    },

    "egp_1095__ch01": {
      "type": "structure",
      "egp_id": 1095,
      "instances": ["There is"]
    },

    "egp_1096__ch01": {
      "type": "structure",
      "egp_id": 1096,
      "instances": ["there are"]
    },

    "egp_222__ch01": {
      "type": "structure",
      "egp_id": 222,
      "note": "Only relative pronoun used at A1. Zero-pronoun contact clauses avoided per constraint spec.",
      "instances": ["who comes"]
    },

    "egp_1058__ch01": {
      "type": "structure",
      "egp_id": 1058,
      "instances": ["picked ... up"]
    },

    "egp_382__ch01__override": {
      "type": "structure",
      "egp_id": 382,
      "override_cefr": "A1",
      "override_reason": "EGP assigns A1. Used above A1 target sparingly -- three careful encounters in internal thought only. L1-transparent (maps to Spanish simple future).",
      "instances": ["will see", "will smile"]
    }
  }
}
```

### Field reference

| Field | Required | Description |
|---|---|---|
| *(key)* | -- | Entry key. Convention: `egp_{id}__{chapter}` for uniqueness in the entries map. Not semantically meaningful. |
| `type` | yes | `"structure"` |
| `egp_id` | yes | Integer. Construct ID from `egpLookup.js`. Provides: CEFR level, superCategory, subCategory, guideword, canDo, example. |
| `note` | no | Book-specific pedagogical rationale. Author/teacher-facing. Why this structure appears, how it's scaffolded. |
| `override_cefr` | no | CEFR level override. Only when the content author has a justified reason to diverge from EGP's assignment. See override policy below. |
| `override_reason` | required if `override_cefr` is set | Explanation of why the override is justified. Must reference a specific rationale (L1 transparency, controlled context, scaffolding, etc.). |
| `instances` | yes | Array of strings. Token sequences to find and highlight in the chapter text. Minimum 1. Supports gap notation (see below). |

### Instance format and gap notation

Instances are plain strings representing token sequences to match
against the chapter text.

| Notation | Meaning | Matches |
|---|---|---|
| `"will see"` | Contiguous tokens. Highlighted as a unit. | "...I **will see** him..." |
| `"picked ... up"` | Gapped tokens. `...` matches 1-5 intervening tokens. Only anchor tokens highlighted. | "...she **picked** the plate **up**..." |
| `"have ... been ... doing"` | Multiple gaps. Each `...` independently matches 1-5 tokens. | For future use at B2+. |

Matching rules:
- Case-insensitive on all tokens
- Reuses the same token stream as word/particle detection
- If the same string matches multiple locations, all are highlighted
- Gap tokens render normally (no highlight); only anchors get the
  structure underline style
- Visual treatment: dotted underline between gapped anchors to show
  they belong to the same structure

## Override Policy

EGP's CEFR level is the default. The content author may override it
in specific, documented cases.

### When an override is justified

1. **L1 transparency** -- the structure maps directly to a Spanish
   equivalent, making it teachable below its EGP level. Example:
   "will future" (EGP: A1) is already at A1, but "there is/are"
   might be easier than expected because Spanish "hay" is taught
   early.

2. **Controlled context** -- the graded reader uses the structure in
   a heavily scaffolded way (e.g., only affirmative form, only with
   high-frequency verbs, only in familiar sentence frames).

3. **Constraint spec rationale** -- the book's constraint spec
   explicitly permits the structure at a different level with
   documented justification.

### When an override is NOT justified

- "I feel like this is A2" without rationale
- Disagreement with EGP based on a single textbook or curriculum
- Wanting to simplify the manifest

### Override format

```json
{
  "type": "structure",
  "egp_id": 382,
  "override_cefr": "A1",
  "override_reason": "L1-transparent: maps directly to Spanish simple future. Used in controlled context: internal thought only, 3 encounters total.",
  "instances": ["will see", "will smile"]
}
```

The reading view uses `override_cefr` for badge color when present,
falling back to `egpLookup[egp_id].level` otherwise.

## Popup Behavior

When a student taps a highlighted structure anchor in the reading view:

### Level 1 -- Summary popup

```
+----------------------------------+
| Will future               [A1]  |  <-- guideword + CEFR badge
|                                  |
| subject + will + verb (base)     |  <-- pattern (from overlay)
|                                  |
| Can use the affirmative forms    |  <-- canDo (from EGP)
| 'will' and ''ll'.               |
|                                  |
| [+ Cloze card]   [Learn more >] |
|                          [Close] |
+----------------------------------+
```

### Level 2 -- Grammar drill-down (tapping "Learn more")

```
+----------------------------------+
| < Will future              [A1] |
|                                  |
| subject + will + verb (base)     |  <-- pattern
|                                  |
| Usamos 'will + verbo' para      |  <-- explanation_es
| hablar del futuro...             |     (from overlay)
|                                  |
| En espanol se usa el futuro      |  <-- spanish_contrast
| simple (vere, sonreira)...       |     (from overlay)
|                                  |
| Examples:                        |
| - I will see you tomorrow.       |  <-- examples (from overlay)
|   Te vere manana.                |
| - She will come later.           |
|   Ella vendra despues.           |
|                                  |
|                          [Close] |
+----------------------------------+
```

### Cloze card creation

Tapping "+ Cloze card" opens CardCreator with the surrounding sentence
(extracted by `extractSentence()` at click time). The student
highlights the portion they want to delete -- same flow as vocabulary
cloze cards. The student studies the grammar explanation first, then
creates their own card based on what they learned.

## Toggle Behavior

Structure highlighting is toggleable independently from vocabulary
highlighting. A toggle in the reading toolbar controls visibility.

- **Students**: off by default. Grammar scaffolding is opt-in.
- **Teachers**: on by default. Preview what to teach.
- **Clean reading mode**: all highlights off.

The `superCategory` field from EGP enables future granular toggles
(show tenses but not clause types) but v1 is a single on/off.
